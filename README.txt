행복네컷 V3.80 (체험 부스용)
===========================

[폴더 구성]
  index.html        프로그램 본체
  sound/            효과음 (intro, ready, 1~5, shot)
  vendor/           오프라인용 리소스 (Tailwind CSS, Lucide 아이콘, QR 생성기, 한글 폰트 10종)
  apps-script/      QR 공유용 구글 Apps Script (Code.gs, Page.html)
  start-kiosk.bat   Windows 부스용 실행 파일

  ※ 인터넷 연결 없이 동작합니다. (QR 공유만 인터넷 필요) 폴더 구조를 그대로 유지해 주세요.

[실행 방법]
  1) 부스(Windows PC) : start-kiosk.bat 더블클릭
     - 전체화면 고정, 카메라 권한 자동 허용, 인쇄 창 없이 바로 인쇄
     - 종료: Alt + F4
  2) 일반 실행        : index.html을 크롬으로 열기 (카메라 권한 창이 뜨면 "허용")
  3) 휴대폰/태블릿     : 웹 서버(https)에 폴더째 올려서 접속 (카메라는 https에서만 동작)

[바로 인쇄 준비]
  1) 포토 프린터를 Windows "기본 프린터"로 지정
  2) 프린터 기본 설정에서 용지를 4x6(10x15cm)로, 여백 없음(테두리 없음)으로 설정
  3) 인쇄물은 같은 띠 2장이 나란히 출력되므로 가운데를 잘라 사용
  ※ start-kiosk.bat이 아닌 일반 크롬에서는 인쇄 창이 뜹니다. 용지 4x6, 여백 없음을 선택하세요.

[V3.80 새 기능] 체험 부스용
  - 대기 화면     : 화면 전체를 덮는 큰 시작 화면 + 데모 애니메이션(3·2·1 → 찰칵 → 네 컷 채우기)
                    켜자마자, 시작 화면에서 20초 동안 입력이 없을 때, 자동 복귀했을 때 나타남
                    화면 터치·클릭·아무 키 → 바로 촬영 화면으로
                    "오늘 벌써 N팀이 찍었어요!" 표시 (결과 화면까지 완성한 횟수, 날짜가 바뀌면 0부터)
  - 큰 화면 맞춤  : 가로 모니터(16인치 등)에서 앱 전체를 화면 높이에 맞춰 확대 (최대 1.8배)
  - 일시 정지     : 촬영 중 "⏸ 일시 정지" 버튼 또는 스페이스바
                    다시 시작하면 이번 사진의 카운트다운을 처음부터 다시 셈 (이미 찍은 사진은 유지)
                    멈춘 채 아무도 없으면 자동 복귀 시간(그 외 화면) 뒤 처음 화면으로
                    촬영 대기 중 스페이스바 = "준비 완료!"
  - 프레임 색     : 프레임 색상 맨 앞 무지개 동그라미 → 추천색 + "원하는 색상"으로 아무 색이나
                    어두운 색을 고르면 제목·날짜 색이 자동으로 밝게 바뀜
  - 최근에 고른 색: 프레임·제목·문구 색상 창에 직접 고른 색 최대 10개 표시 (이 기기에 저장)
  - 관리자 설정 → "대기 화면 (체험 부스용)": 사용 여부, 나타나는 시간(10초~2분), 오늘 N팀 표시·초기화,
                  큰 화면에 맞춰 키우기, 대기 화면 미리 보기

  [부스 운영 팁]
  - 크롬에서 index.html을 열고 오른쪽 위 전체화면 버튼(또는 F11) → 대기 화면이 모니터 전체에 표시됨
  - 첫 실행 때 화면을 한 번 눌러 카메라 권한을 허용해 두면 이후에는 바로 촬영 화면으로 넘어감
  - 노트북 화면이 아닌 외부 모니터 쪽에 크롬 창을 옮긴 뒤 전체화면으로 전환

[V3.70 새 기능]
  - 사진 크게      : 2x6 띠의 여백을 줄여 사진 칸을 키움 (420x302 → 520x374, 면적 약 1.5배)
                     가로 2x2도 사진 칸 620 → 700으로 키움
                     제목은 맨 위, 문구와 날짜는 맨 아래 여백에 들어감
  - 고화질 출력    : 화면에는 프레임 크기로 보여주고, 저장·인쇄·QR 사진은 원본 해상도 기준으로
                     2~2.5배 크게 다시 그림 (2x6 띠 1500x4500, 4x6 출력용 3000x4500)
                     카메라도 지원하면 1920x1440으로 촬영
  - 사진 조절      : 프레임 화면에서 사진을 누르면 네 꼭짓점이 나타남
                     끌기 = 이동 / 꼭짓점 끌기·두 손가락 = 확대·축소(최대 4배) / 두 번 누르기 = 원래대로
                     PC는 마우스 휠로도 확대·축소, 왼쪽 "사진 조절"의 － ＋ ↺ 버튼도 사용 가능
  - 저장·인쇄 QR   : 저장 버튼을 누르면 QR 창이 먼저 뜸 → 휴대폰으로 찍어 바로 저장
                     (창 아래 "이 기기에 파일로 저장"으로 부스 기기에도 저장 가능)
                     바로 인쇄 후에도 QR 창이 자동으로 뜸
                     관리자 설정 → "저장·인쇄할 때 QR 보여주기"로 켜고 끔 (기본: 켬)
                     ※ QR 공유 주소가 연결되어 있어야 함 (아래 [QR 공유 설정]). Apps Script는 V3.60 그대로 사용 가능

[QR 공유 설정] (처음 한 번)
  사진은 QR 코드에 직접 담기에 너무 크기 때문에, 선생님 구글 드라이브에 올린 뒤
  그 사진 페이지 주소를 QR 코드로 보여줍니다.

  1) https://script.google.com 접속 → "새 프로젝트"
  2) Code.gs 내용을 지우고 apps-script/Code.gs 내용을 붙여넣기
  3) 왼쪽 "파일 +" → HTML → 이름을 Page 로 만들고 apps-script/Page.html 내용 붙여넣기
  4) Code.gs 맨 위 "const SHARED_KEY = 'change-me';" 줄의 따옴표 안만 나만 아는 값으로 바꾸고 저장
     (찾기·바꾸기로 모두 바꾸지 말고 이 한 줄만 고치기)
     (KEEP_DAYS: 사진 보관 일수, 기본 7일)
  5) 함수 선택에서 authorize 실행 → 드라이브 권한 "허용"
  6) 함수 선택에서 setupCleanupTrigger 한 번 실행 → 보관 기간이 지난 사진 매일 자동 삭제
  7) 오른쪽 위 "배포" → "새 배포" → 유형: 웹 앱
       - 실행 사용자: 나
       - 액세스 권한이 있는 사용자: 모든 사용자   ← "나만"이면 QR 업로드가 안 됨 (가장 흔한 원인)
     → 배포 후 나오는 웹 앱 주소(…/exec) 복사
  8) 행복네컷 관리자 설정(제목 3초 길게 누르기) → "QR 공유"
       - Apps Script 웹 앱 주소, 공유 키(4번 값) 입력 → "연결 테스트"에서 "연결 성공" 확인

  ※ 학교(교육청) 구글 계정은 "모든 사용자" 배포나 외부 공유가 막혀 있을 수 있습니다.
    이때는 개인 Gmail 계정으로 만들어 주세요.
  ※ Code.gs를 고친 뒤에는 "배포 관리" → 연필 → 버전 "새 버전"으로 다시 배포해야 반영됩니다.
  ※ 사진은 드라이브 "행복네컷 공유" 폴더에 저장되며, QR 주소를 아는 사람은 누구나 볼 수 있습니다.
    학생 사진이므로 보관 기간을 짧게 두고, 행사 후 폴더를 정리해 주세요.

[코드를 수정할 때]
  vendor/tailwind.css는 index.html에 쓰인 클래스만 담아 미리 만든 파일입니다.
  index.html에 새로운 Tailwind 클래스를 추가했다면 아래 명령으로 다시 만들어야 적용됩니다.
    npx tailwindcss@3 -i in.css -o vendor/tailwind.css --content index.html --minify
    (in.css 내용:  @tailwind base; @tailwind components; @tailwind utilities;)
